# Appels d'Offres Maroc

Application Flask permettant de scraper et rechercher des appels d’offres sur plusieurs sites publics marocains.

## Fonctionnalités

- Recherche simple par mot-clé
- Recherche avancée par critères
- Support de plusieurs sources (Ministère des Finances, Crédit Agricole, PMMP)
- Interface web et API JSON
